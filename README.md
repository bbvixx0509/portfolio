# 개발 포트폴리오

강원대학교 AI소프트웨어학과 지민구입니다. 클라우드 인프라와 분산 시스템에 관심이 있습니다.  
팀 프로젝트에서 개발과 클라우드를 함께 맡으면서 쿠버네티스 운영과 CI/CD·인프라 코드 같은 DevOps 쪽에 비중을 두었고, 배포한 서비스를 부하 테스트와 장애 실험으로 측정해 근거를 갖고 고치는 작업을 해 왔습니다.

- **FoodiGuard**: 팀에서 진행한 성능 개선을 운영 환경에서 다시 측정하다가 DB 뷰에서 쓰이지 않던 부분 인덱스를 실행계획으로 찾아 고쳐, 기본 목록 응답을 361ms에서 24ms로 줄였습니다. 이후 부하 테스트에서 남은 검색 경로의 병목이 API가 아니라 1 vCPU Cloud SQL이라는 것도 확인했습니다.
- **FoodiGuard**: GKE에서 API 파드를 강제로 삭제하는 장애 실험으로 약 4초 정지를 확인해 기록했고, 이 결과를 바탕으로 팀에서 API 복제본 2개와 PodDisruptionBudget을 적용했습니다.
- **FoodiGuard**: 팀원과 함께 마이그레이션이 성공해야만 배포를 갱신하는 Jenkins 파이프라인과 Terraform 인프라 코드를 구성했고, 그중 콘솔에서 따로 관리하던 알림 정책을 Terraform 코드로 옮기는 일을 맡았습니다.
- **NoDo**: 팀원과 함께 Firestore 트랜잭션으로 저장 용량을 예약 → 확정 → 해제하도록 구현해, 여러 자료를 동시에 올려도 한도를 넘지 않게 했습니다.

## 대표 프로젝트

### [GKE 기반 건강식 장바구니 분석 서비스 FoodiGuard](./GKE%20기반%20건강식%20장바구니%20분석%20서비스%20FoodiGuard)
식품 79,041건을 기반으로 영양·원재료·알레르기 분석과 대체식품 추천을 제공하는 모바일 서비스를 GKE와 Cloud SQL에 배포한 팀 프로젝트입니다.  
Jenkins CI/CD, Terraform, Managed Prometheus 알림을 갖추고, 쓰이지 않던 인덱스를 고쳐 기본 목록 응답을 약 15배(361ms → 24ms) 줄인 과정과 부하 테스트·장애 실험으로 운영 가능성을 검증한 과정까지 담았습니다.

### [Google Cloud 기반 수업 운영 플랫폼 NoDo](./Google%20Cloud%20기반%20수업%20운영%20플랫폼%20NoDo)
React → FastAPI(Cloud Run) → Firestore·Cloud Storage·Vertex AI 구조로 만든 AI 수업 로드맵·실시간 강의 운영 플랫폼입니다.  
권한, 개인정보, 용량 예약, 데이터 수명주기를 서버에서 일관되게 처리하도록 설계한 Google Cloud 산학 프로젝트입니다.

### [LangGraph 기반 식단 추천 AI 에이전트](./LangGraph%20기반%20식단%20추천%20AI%20에이전트)
LangGraph와 Gemini로 자연어 식단 요청을 해석하고, 약 4만 건의 식품 데이터에서 Python 로직으로 후보를 계산해 추천 근거와 함께 보여주는 AI 에이전트입니다.  
이후 FoodiGuard 클라우드 서비스로 확장된 출발점이 된 프로젝트입니다.

- 각 프로젝트 README에는 프로젝트 목적, 핵심 기능, 확인하면 좋은 파일, 실행 화면 또는 결과 예시를 함께 넣었습니다.
- 읽는 사람이 파일 구조에 먼저 막히지 않도록 폴더 이름과 프로젝트 설명을 한국어 중심으로 정리했습니다.
- 빌드 결과물, 개인 메모, 원본 발표 자료처럼 GitHub에서 바로 볼 필요가 없는 파일은 `.gitignore`로 제외했습니다.
- 팀 프로젝트는 각 README에 `내가 맡은 역할`을 따로 적었고, 협력 기업의 클라우드 프로젝트 ID·조직 정보, 외부 IP, 개인 이메일, API 키처럼 공개되면 안 되는 값은 예시 값으로 바꾸거나 제외했습니다.

# 푸디가드 UI 수정 요청 정리

이번 UI 수정의 핵심 방향은 MVP/연구/검증/데모 느낌이 나는 문구와 옵션을 제거하고, 사용자에게 필요한 기본 서비스 화면만 남기는 것입니다.

## 1. 페르소나 관련

- [ ] 페르소나는 `기본 체중조절형`만 남기기
- [ ] 나머지 페르소나 옵션 제거

## 2. 매칭/샘플/원천 관련 옵션 제거

- [ ] `매칭원천` 제거
- [ ] `정확/유사` 선택 제거
- [ ] `MVP 샘플` 제거
- [ ] `Cloud SQL` 선택란 제거
- [ ] `Naver` 선택란 제거

## 3. 장바구니 담을 때 뜨는 UI 제거

- [ ] 장바구니 담을 때 나타나는 파란색 안내 글자 제거
- [ ] 장바구니 담을 때 뜨는 `평가 신뢰도` 박스 제거
- [ ] 장바구니 담을 때 뜨는 `원본 DB 대조` 박스 제거

## 4. 연구/데모 관련 박스 제거

- [ ] `연구 검증 포인트` 박스 제거
- [ ] `GCP demo stack` 박스 제거

## 5. 상단/헤더 영역 정리

- [ ] 맨 위에 작게 보이는 `단일 추천`, `다중 분석` 문구 제거
- [ ] 오른쪽 상단 `회원가입 없는 테스트 모드` 제거
- [ ] 왼쪽 상단 `Cloud SQL Research MVP` 문장 제거

## 6. 메인 로고 주변 문구 제거

- [ ] 큰 로고 `푸디가드`는 유지
- [ ] `푸디가드` 위의 `Cloud SQL matched research MVP` 문구 제거
- [ ] 아래 설명 문구 제거

제거할 설명 문구:

```text
Cloud SQL에 적재한 네이버 매칭 영양 데이터와 쇼핑 검색을 함께 비교해 단일 상품 추천과 장바구니 조합 분석을 검증합니다.
```

## 최종 목표

- `푸디가드` 서비스명과 핵심 추천/장바구니 기능은 유지
- 연구용 MVP, Cloud SQL, Naver, 검증, 샘플, 데모, 테스트 모드 관련 표현 제거
- 장바구니 담기 이후 불필요한 보조 정보 박스 제거

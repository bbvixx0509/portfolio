# 푸디가드 동의 문구 (앱 실제 노출 문구)

이 문서는 `backend/server/consentDocuments.js` 에서 자동 생성됩니다. 직접 고치지 마세요.

- 생성 명령: `cd backend && npm run consents:print > ../docs/irb-consent.md`
- 아래 문구는 앱 가입 화면(동의 화면)에서 "전문 보기"를 눌렀을 때 표시되는 내용과 글자 단위로 같습니다.
- 전문 해시(SHA-256)는 동의 시 `user_consents.content_hash` 에 저장되므로, 회원이 어떤 판본의 어떤 문장에 동의했는지 대조할 수 있습니다.

## 동의 항목 요약

| 구분 | 동의 유형(consent_type) | 판본 | 화면 문구 | 전문 해시 |
| --- | --- | --- | --- | --- |
| 필수 | `PRIVACY` | 1.0 | (필수) 개인정보 수집·이용에 동의합니다 | `5c565cbf79dfba85…` |
| 필수 | `HEALTH_DATA` | 1.0 | (필수) 건강정보 수집·이용에 별도로 동의합니다 | `fbd51f17d246a273…` |
| 필수 | `NON_MEDICAL_NOTICE` | 1.0 | (필수) 위 안내를 읽고 이해했음을 확인합니다 | `2fad3c7b12b9a24e…` |

## 개인정보 수집·이용 동의

- 유형: `PRIVACY` / 판본: `1.0` / **필수**
- 전문 해시(SHA-256): `5c565cbf79dfba858d7ba7813f2e2561d82365ca08dd5d574eb313136c749e59`
- 체크박스 문구: **(필수) 개인정보 수집·이용에 동의합니다**
- 요약 문구: 계정을 만들고 로그인하는 데 필요한 정보를 받습니다.

### 전문

**수집 항목과 이용 목적, 보유 기간**

「개인정보 보호법」 제15조제2항에 따라 아래 내용을 알려 드립니다.

| 항목 | 내용 |
| --- | --- |
| 수집 항목 | 이름, 이메일 주소, 비밀번호, 가입 일시 |
| 이용 목적 | 회원 계정 생성과 회원 식별, 로그인 인증, 회원님이 입력하신 조건을 계정에 연결해 다음 접속 때 그대로 불러오기 |
| 보유·이용 기간 | 계정이 삭제될 때까지 보유하며, 삭제 시 계정에 연결된 프로필·알레르기·동의 이력이 함께 파기됩니다. |

**비밀번호를 다루는 방법**

비밀번호는 원문을 저장하지 않고 되돌릴 수 없는 해시 값으로 변환해 보관합니다. 푸디가드 팀도 회원님의 비밀번호 원문을 확인할 수 없습니다.

**제3자 제공과 광고 이용**

- 이름과 이메일 주소를 제3자에게 제공하거나 판매하지 않습니다.
- 광고나 마케팅 목적으로 이용하지 않습니다.
- 이름과 이메일 주소는 외부 인공지능 서비스로 전송되지 않습니다. 어떤 정보가 외부로 전송되는지는 다음 항목인 건강정보 동의에서 따로 안내해 드립니다.

**삭제·열람을 원하실 때**

현재 앱 화면에는 회원이 직접 탈퇴하는 기능이 없습니다. 계정 삭제나 저장된 정보의 열람·정정을 원하시면 푸디가드 운영팀에 요청해 주세요. 요청을 받으면 계정과 그에 연결된 정보를 지체 없이 파기해 드립니다.

**이용 연령**

푸디가드는 만 14세 이상만 이용하실 수 있습니다. 만 14세 미만 아동은 「개인정보 보호법」 제22조의2에 따라 법정대리인의 동의가 필요하며, 현재 앱은 법정대리인 동의를 받는 절차를 제공하지 않으므로 가입하지 말아 주세요.

> 회원님은 이 동의를 거부하실 권리가 있습니다(「개인정보 보호법」 제15조제2항제4호). 다만 위 항목은 계정을 만들고 유지하는 데 반드시 필요하므로, 거부하시면 서비스를 이용하실 수 없습니다.

## 건강정보(민감정보) 수집·이용 동의

- 유형: `HEALTH_DATA` / 판본: `1.0` / **필수**
- 전문 해시(SHA-256): `fbd51f17d246a2735523b4a910f3214350791dc1bfe8b10255a1552daa54b808`
- 체크박스 문구: **(필수) 건강정보 수집·이용에 별도로 동의합니다**
- 요약 문구: 키·체중·알레르기는 민감정보여서 앞의 동의와 나누어 따로 받습니다.

### 전문

**이 동의를 따로 받는 이유**

건강에 관한 정보와 알레르기 정보는 「개인정보 보호법」 제23조가 정한 민감정보입니다. 민감정보는 다른 개인정보의 처리에 대한 동의와 묶어서 받을 수 없고 반드시 별도로 동의를 받아야 하므로, 앞의 개인정보 동의와 분리해 여쭙습니다.

**수집 항목과 이용 목적, 보유 기간**

| 항목 | 내용 |
| --- | --- |
| 수집 항목 | 성별, 생년월일, 키, 체중, 활동량, 식생활 목표 |
| 알레르기 항목 | 알류(가금류), 우유, 메밀, 땅콩, 대두, 밀, 호두, 잣, 고등어, 게, 새우, 오징어, 조개류, 돼지고기, 닭고기, 쇠고기, 복숭아, 토마토, 아황산류 19종 가운데 회원님이 고르신 항목 |
| 이용 목적 | 「한국인 영양소 섭취기준(KDRIs) 2025」에 따른 1일 영양 기준(열량·단백질·나트륨·당류·포화지방) 계산, 식생활 목표에 따른 식품 점수와 정렬 기준 결정, 고르신 알레르기 유발 식품을 검색·추천·장바구니에서 제외, 담아 둔 식품의 영양 합계 분석과 대체 식품 제안 |
| 보유·이용 기간 | 계정이 삭제될 때까지. 삭제 시 프로필과 알레르기 정보가 함께 파기됩니다. |

**외부 인공지능 서비스로 전송되는 정보**

분석 화면에서 회원님이 「AI 설명 보기」를 직접 누르시면, 설명 문구를 만들기 위해 아래 정보가 Google Cloud Vertex AI(Gemini)로 전송됩니다. 이 기능을 사용하지 않으시면 전송되지 않습니다.

| 항목 | 내용 |
| --- | --- |
| 수탁자 | Google Cloud Vertex AI (Google LLC) |
| 위탁 업무 | 장바구니 영양 분석 결과를 설명하는 문장 자동 생성 |
| 전송 항목 | 성별, 만 나이, 키, 체중, 활동량, 식생활 목표, 고르신 알레르기 항목명, 담아 둔 식품명과 영양성분 수치 |
| 전송되지 않는 항목 | 이름, 이메일 주소, 비밀번호, 생년월일 원본 |
| 이전되는 국가 | 현재 Google 글로벌 리전으로 요청하므로 대한민국 밖에서 처리될 수 있습니다. |

**그 밖의 이용 범위**

- 건강정보는 회원님 화면에 보여 드릴 결과를 계산하는 데에만 쓰이며, 제3자에게 제공하거나 판매하지 않습니다.
- 광고나 마케팅 목적으로 이용하지 않습니다.
- 알레르기 항목은 고르지 않으셔도 가입하실 수 있습니다. 다만 고르지 않으시면 알레르기 제외 기능이 동작하지 않습니다.
- 입력하신 건강정보는 마이 페이지의 「내 조건」에서 언제든 다시 고치실 수 있습니다.

> 회원님은 이 동의를 거부하실 권리가 있습니다(「개인정보 보호법」 제15조제2항제4호, 제23조제1항제1호). 다만 위 항목은 개인별 영양 기준 계산과 알레르기 제외라는 푸디가드의 핵심 기능에 반드시 필요하므로, 거부하시면 서비스를 이용하실 수 없습니다.

## 비의료 건강관리서비스 안내

- 유형: `NON_MEDICAL_NOTICE` / 판본: `1.0` / **필수**
- 전문 해시(SHA-256): `2fad3c7b12b9a24e51d121e50d3cfe3f373ade127263049b0e4d38b069b4a8f8`
- 체크박스 문구: **(필수) 위 안내를 읽고 이해했음을 확인합니다**
- 요약 문구: 푸디가드는 의료기기가 아니며 진단·치료를 하지 않습니다. 꼭 읽어 주세요.

### 전문

**푸디가드의 성격**

푸디가드는 가공식품의 영양성분 자료를 회원님이 입력하신 조건에 맞춰 비교해 보여 드리는 비의료 건강관리서비스입니다. 「의료기기법」상의 의료기기가 아니고, 「의료법」상의 의료행위를 하지 않습니다. 질병을 다루는 서비스가 아니라 일상적인 식품 선택을 돕는 보조 도구입니다.

**이런 목적으로는 이용하실 수 없습니다**

- 질병을 진단하거나 질병이 있는지 판정하는 목적
- 질병을 치료·경감·처치하거나 예방하는 목적
- 의사의 진료·검사·처방이나 복약 지도를 대신하는 목적
- 특정 식품이 특정 질병에 효능이 있다고 판단하는 근거

**보여 드리는 값의 출처**

- 식품의 영양성분과 원재료: 식품의약품안전처 통합식품영양성분DB와 품목제조보고 원재료 자료
- 알레르기 유발물질 19종의 범위: 식품의약품안전처 고시 「식품등의 표시기준」
- 1일 영양 기준의 산출 근거: 보건복지부·한국영양학회 「한국인 영양소 섭취기준(KDRIs) 2025」

**한계를 알려 드립니다**

- 1일 영양 기준과 식품 점수는 건강한 성인을 기준으로 계산한 참고 값이며, 회원님의 몸 상태를 진단한 결과가 아닙니다.
- 영양성분 값은 앱이 보유한 자료를 기준으로 하므로 실제 제품의 표시사항과 다를 수 있습니다. 구매·섭취 전에는 제품 포장의 표시사항을 직접 확인해 주세요.
- 알레르기 제외 기능은 자료에 기록된 원재료를 기준으로 동작합니다. 자료에 적히지 않은 미량 성분이나 제조 과정에서의 혼입까지 걸러내지는 못하므로 완전한 차단을 보장하지 않습니다.
- 「AI 설명 보기」로 만들어지는 문장은 인공지능이 자동으로 생성한 것이라 사실과 다를 수 있으며, 의학적 조언이 아닙니다.

**이런 경우에는 전문가와 먼저 상의해 주세요**

질환을 진단받으셨거나 치료 중이신 경우, 임신·수유 중이신 경우, 알레르기로 심한 반응을 겪으신 적이 있는 경우에는 이 앱의 결과에 따라 식사를 바꾸시기 전에 의사나 임상영양사와 먼저 상의해 주세요. 이용 중 몸에 이상이 느껴지면 이용을 멈추고 의료기관의 진료를 받으시기 바랍니다.

> 이 확인은 서비스의 성격을 오해 없이 이해하신 상태로 이용하시는 데 반드시 필요합니다. 확인을 거부하실 권리가 있으나, 거부하시면 서비스를 이용하실 수 없습니다.
